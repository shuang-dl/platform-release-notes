Release v9.4.52 — 2026-07-28

View original Slack post · 1785242394.768199

Summary

This release ships six changes across PM Operations (clickable maintenance-task links, Properties list grouping by portfolio/owner, and a cleaner lease renewal overview), Tenant Experience & Payments (an AR dashboard filter and performance fix), and Workflows (a 7-step lease-renewal agent and a Communications settings empty state). Most changes are customer-visible; one (the AR dashboard fix) is an internal bug fix with no documentation impact.
