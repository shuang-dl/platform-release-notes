Summary

This small release ships 2 changes: an internal security hardening fix in Onboarding & Imports (ACT-1362, adding authenticated bearer-token requests to the GSF AI migration service) and a Tenant Experience & Payments improvement (TEN-1101) that persists each user's custom dashboard widget layout and sizes across sessions. Only the dashboard layout change is customer-visible; the migration-service auth change is backend-only.

ACT-1362 Secure the AI data-migration service with a bearer token Added authenticated migration requests when a service token is configured, while keeping existing behavior when it is not. The server-side proxy that calls the GSF AI migration service now attaches an Authorization: Bearer <token> header whenever the ROSETTA_SERVICE_TOKEN secret is configured (which it will be in prod), and sends no auth header when it isn't (local dev). This is a backend security hardening change with no visible UI difference for property managers. INTERNAL — no Help Center change; purely a server-to-server auth header added to the AI data-migration proxy, no user-facing workflow changed.
