Summary

TEN-1093 Tenant-portal insurance-shown endpoint ported to new server Added support for marking the insurance offer as shown in the tenant portal, with duplicate updates prevented. Purely a backend migration: the "mark insurance offer shown" endpoint was added to the new tenant-portal-server (behind a flag) to match the already-migrated snooze endpoint, so the legacy and new servers don't diverge. Behavior for tenants and PMs is unchanged. INTERNAL — flag-gated backend server-migration parity work; no user-facing behavior change, so no Help Center update needed. — no related video
TEN-1042 Bulk Send Auto-Pay Request for leases Added a bulk Send Auto-Pay Request action for leases, with per-lease results and duplicate-request protection. Property managers can now select multiple leases in the lease list and send an Auto-Pay request email to all eligible tenants at once (last payment via portal, AutoPay not yet set, portal access enabled, not in eviction), instead of doing it lease-by-lease. Ineligible leases are skipped, and a 7-day throttle prevents duplicate requests. MATCHED — How to Set Up Auto-Pay on the Resident Center
Likely update needed: add a section covering the PM-side bulk "Send Auto-Pay Request" action from the lease list, separate from the tenant self-service setup this article currently documents.		 — no related video
TEN-1119 Duplicate insurance-offer popup removed Removed legacy insurance offer events so tenants no longer see duplicate Intercom popups. Tenants were briefly seeing two insurance-offer popups — the new native in-app dialog plus a legacy Intercom-triggered one firing off the same event. The legacy event emission was removed so tenants only see the single native popup going forward. INTERNAL — silent analytics/dedup bugfix; the tenant-facing insurance popup itself is unchanged and already documented, so no article update needed. — no related video
TEN-1120 Tenant fees now always labeled DoorLoop Platform Fee Now presents tenant payment fees as DoorLoop Platform Fee instead of processing fee wording. Per outside counsel (to avoid surcharging concerns), the tenant portal no longer describes DoorLoop's fee as a "processing fee" or "card processing fee" anywhere in the payment wizard or payment-methods screens (English and Spanish). It's now consistently labeled "DoorLoop Platform Fee," with a new tooltip explaining it's DoorLoop's fee for platform use — the amount/percentage shown is unchanged. MATCHED — Tenant Platform Fees on the Portal
Likely update needed: remove any remaining "processing fee" / "card processing fee" wording and screenshots, and confirm the tooltip copy matches the new counsel-approved text ("DoorLoop Platform Fee ... for paying via its platform").		 Fees Settings Overview (created Mar 18, 2026 — 127 days before this release) — likely needs updating if it shows tenant-facing "processing fee" wording that has now changed.
